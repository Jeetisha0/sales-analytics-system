# Sales Analytics System

This project implements an end-to-end sales analytics pipeline using Python.
It covers data cleaning, analysis, API-based enrichment, and report generation.

## Project Structure

sales-analytics-system/
├── main.py
├── utils/
│   ├── file_handler.py
│   ├── data_processor.py
│   └── api_handler.py
├── data/
│   └── sales_data.txt
├── output/
├── requirements.txt
└── README.md

## Setup Instructions

1. Clone the repository
2. Install required dependencies:

pip install -r requirements.txt

## Run Instructions

Execute the application using:

python main.py

## Outputs

- Enriched sales data file:
  data/enriched_sales_data.txt

- Sales analytics report:
  output/sales_report.txt
